## Event Flow

### 1. User Registration in Keycloak
```
Keycloak → Kafka (keycloak-events topic)
         → users-be consumes event
         → Creates user in PostgreSQL
         → Creates outbox event
         → Outbox processor publishes to Kafka (user-events topic)
```

### 2. User Update via API
```
HTTP PUT /api/v1/users/:id
         → User service updates user
         → Transaction: Update user + Create outbox event
         → Outbox processor publishes to Kafka
```

### 3. Outbox Pattern Flow
```
Business Operation (e.g., create user)
         → Save user to database
         → Save event to outbox table (same transaction)
         ✓ Transaction committed (atomic)
         
Outbox Processor (background)
         → Poll outbox table every 5 seconds
         → Find pending events
         → Publish to Kafka
         → Mark event as published
         → Retry failed events with exponential backoff
```
