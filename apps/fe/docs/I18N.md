# Internationalization (i18n)

Guide for managing translations and adding new languages.

## Overview

Skillsier uses a file-based i18n system with:
- Auto-detecting user locale
- RTL support for Arabic
- Type-safe translation keys
- Shared translations across web/mobile

## Architecture
```
packages/i18n/
├── src/
│   ├── locales/
│   │   ├── en/          # English
│   │   │   ├── common.json
│   │   │   ├── auth.json
│   │   │   └── jobs.json
│   │   └── ar/          # Arabic
│   │       ├── common.json
│   │       ├── auth.json
│   │       └── jobs.json
│   ├── hooks/
│   │   └── useTranslation.ts
│   └── config.ts
```

## Supported Languages

- **English (en)** - Default
- **Arabic (ar)** - RTL support

## Usage

### Basic Translation
```typescript
import { useTranslation } from '@skillsier/i18n';

function MyComponent() {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t('common.welcome')}</h1>
      <p>{t('auth.signIn')}</p>
    </div>
  );
}
```

### With Variables
```typescript
const { t } = useTranslation();

// Translation file: "Hello, {{name}}!"
t('common.greeting', { name: 'John' })
// Output: "Hello, John!"
```

### Pluralization
```typescript
const { t } = useTranslation();

// Translation file:
// "job": "{{count}} job",
// "job_plural": "{{count}} jobs"

t('jobs.count', { count: 1 })  // "1 job"
t('jobs.count', { count: 5 })  // "5 jobs"
```

### Locale Switching
```typescript
import { useTranslation } from '@skillsier/i18n';

function LocaleSwitcher() {
  const { locale, setLocale } = useTranslation();
  
  return (
    <select value={locale} onChange={(e) => setLocale(e.target.value)}>
      <option value="en">English</option>
      <option value="ar">العربية</option>
    </select>
  );
}
```

## Adding a New Language

### 1. Create Locale Folder
```bash
cd packages/i18n/src/locales
mkdir es  # Spanish example
```

### 2. Copy Translation Files
```bash
# Copy from English as template
cp -r en/* es/
```

### 3. Translate Content

Edit `es/common.json`:
```json
{
  "welcome": "Bienvenido",
  "loading": "Cargando...",
  "error": "Error",
  "success": "Éxito"
}
```

Edit `es/auth.json`:
```json
{
  "signIn": "Iniciar sesión",
  "signOut": "Cerrar sesión",
  "email": "Correo electrónico",
  "password": "Contraseña"
}
```

Edit `es/jobs.json`:
```json
{
  "title": "Trabajos",
  "create": "Publicar trabajo",
  "viewAll": "Ver todos"
}
```

### 4. Update Config

Edit `packages/i18n/src/config.ts`:
```typescript
export const SUPPORTED_LOCALES = ['en', 'ar', 'es'] as const;

export const LOCALE_NAMES = {
  en: 'English',
  ar: 'العربية',
  es: 'Español',
};
```

### 5. Test Translations
```bash
pnpm --filter @skillsier/i18n build
pnpm --filter @skillsier/i18n test
```

## RTL Support

### Automatic RTL

Arabic automatically applies RTL:
```typescript
const { dir } = useTranslation();
// dir = 'rtl' when locale is 'ar'
```

### Manual RTL Styling
```typescript
import { useTranslation } from '@skillsier/i18n';

function MyComponent() {
  const { dir } = useTranslation();
  
  return (
    <div dir={dir} className={dir === 'rtl' ? 'text-right' : 'text-left'}>
      Content
    </div>
  );
}
```

### Tailwind RTL

Use Tailwind's RTL utilities:
```jsx
<div className="ml-4 rtl:mr-4 rtl:ml-0">
  Content
</div>
```

## Best Practices

### 1. Use Namespaces

Group related translations:
```json
{
  "jobs": {
    "create": "Create Job",
    "edit": "Edit Job",
    "delete": "Delete Job"
  }
}
```

Access: `t('jobs.create')`

### 2. Keep Keys Descriptive

❌ Bad:
```json
{ "btn1": "Click me" }
```

✅ Good:
```json
{ "submitButton": "Submit" }
```

### 3. Extract Repeated Strings

❌ Bad:
```json
{
  "deleteJob": "Delete Job",
  "deleteUser": "Delete User",
  "deleteContract": "Delete Contract"
}
```

✅ Good:
```json
{
  "delete": "Delete",
  "job": "Job",
  "user": "User",
  "contract": "Contract"
}
```

Use: `t('delete') + ' ' + t('job')`

### 4. Handle Missing Translations
```typescript
const { t } = useTranslation();

// Falls back to key if missing
t('nonexistent.key')  // Returns "nonexistent.key"

// Provide fallback
t('optional.key', { fallback: 'Default Text' })
```

## Troubleshooting

### Missing translations

Check browser console for warnings:
```
[i18n] Missing translation: "jobs.missing.key"
```

### RTL not working

- Verify `dir={dir}` is set on root element
- Check Tailwind RTL plugin is configured
- Ensure Arabic locale is selected

### Pluralization issues

Ensure both singular and plural forms exist:
```json
{
  "job": "{{count}} job",
  "job_plural": "{{count}} jobs"
}
```
