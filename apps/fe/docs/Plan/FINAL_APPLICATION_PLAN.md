## 💡 Best Practices

### Code Organization
```typescript
// ✅ Good: Feature-based structure
packages/shared/src/features/
  ├── auth/
  ├── user/
  ├── proposals/    ← Add new features here
  └── contracts/

// ❌ Bad: Type-based structure
src/
  ├── components/
  ├── hooks/
  └── api/
```

### API Calls
```typescript
// ✅ Good: Use hooks
const { data, isLoading } = useFreelancerProfile();

// ❌ Bad: Direct API calls
const data = await userApi.getFreelancerProfile();
```

### State Management
```typescript
// ✅ Good: TanStack Query for server state
const { data } = useQuery({
  queryKey: ['key'],
  queryFn: fetchFn,
});

// ✅ Good: Zustand for client state
const user = useAuthStore((state) => state.user);

// ❌ Bad: useState for server data
const [user, setUser] = useState(null);
```
